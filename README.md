# 🏢 Apartment Booking Form (Multi-Page HTML Project)

A clean, semantic, and user-friendly **Multi-Page Apartment Booking Form** website built purely using **HTML5**. This project allows users to explore different accommodation types, review security and privacy policies, and submit their booking details.

---

## 📌 Features

- **Multi-Page Navigation:** Separate dedicated pages for exploration, luxury suites, standard options, and booking forms.
- **Semantic HTML5:** Built with clean structure and semantic elements (`<header>`, `<main>`, `<section>`, `<form>`, etc.).
- **Security & Privacy Policy:** Clear terms regarding guest ID verification, data privacy, building CCTV security, and refundable deposits.
- **Responsive Layout & Form Elements:** Includes structured input fields for guest details, check-in dates, and apartment selection.
